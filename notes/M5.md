 Plan: Add tags key to notes

     Context

     Notes currently store only title and body. This task adds a tags key (list of strings) to every note created via the form. When no tags are submitted, tags defaults to []. This lays the groundwork for tag-based filtering in future tasks.

     Change

     File: app.py — line 29

     Current:
     app.notes.append({"title": title, "body": body})

     New:
     tags = request.form.getlist("tags")
     app.notes.append({"title": title, "body": body, "tags": tags})

     request.form.getlist("tags") returns [] naturally when no tags field is present in the submitted form — no hardcoded default value needed.

     Why this approach

     - getlist is the idiomatic Flask way to read a multi-value form field; it returns [] when the field is absent.
     - No changes to templates, routes, or existing tests required.
     - All existing tests (test_task_01.py, test_task_02.py) only check title, body, and redirect behavior — they are unaffected.

     Verification

     1. Run pytest — all existing tests must pass.
     2. In a Python shell or test, POST to /notes/new without a tags field and confirm app.notes[-1]["tags"] == [].
