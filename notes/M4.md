## Bug hunt #1 — SQL injection
- Bug: The user input q is directly executed into the SQL command.
- Why Claude wrote it: It is similar to using a F string so claude would think it to be natural to use a similar method to run the SQL query.
- Fix: Using bound parameters or SQLAlchemy's query API.

## Bug hunt #3 — edge case
- Bug: It did not account for if there was 0 and it is possible for there to be a ZeroDivisionError
- Why Claude wrote it: It assumed the bets case scenario and did not think about edge cases.
- Fix: Making sure that the ratings is not zero prior to division and returning accordingly.
